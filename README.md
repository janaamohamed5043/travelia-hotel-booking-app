
1. Project Name

Travelia - a hotel booking application UI/UX Design

2. Project Idea

Travelia is a hotel booking application that simplifies the process of finding and reserving hotel rooms. It allows users to search for hotels by city or hotel name and explore available accommodation options based on their preferences.
When searching for a specific city, users can browse a list of available hotels, view different room types (Single, Double, Suite, and more), and compare accommodation options. The application also provides customizable filters to help users narrow down their search and find hotels that best match their needs.
Travelia aims to provide a seamless, convenient, and user-friendly booking experience by connecting travelers with hotels and making it easier to discover and reserve the perfect stay.
